Praktilised kursused süsteemiadministraatoritele ja IT-taristu haldajatele.

Iga kursus on üles ehitatud laborite ümber: osaleja saab oma virtuaalmasinad kooli Proxmoxi keskkonnas, esitab töö GitHubis ja saab automaatse tagasiside iga push'i järel.

## Kursused

**[IT-infrastruktuuri automatiseerimine](https://hkhk-tk.github.io/is1-automatiseerimine/)**
Bash, Ansible, Docker, OpenTofu, Kubernetes, CI/CD
